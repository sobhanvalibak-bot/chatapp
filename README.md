# اپ چت (Flutter + Node.js)

ثبت‌نام و ورود با نام کاربری و رمز عبور، چت لحظه‌ای، ظاهر شبیه تلگرام/iOS.

```
chatapp/
├── server/   ← سرور (Node.js) – اول روی Termux، بعد روی هاست
├── app/      ← اپ Flutter
└── .github/workflows/build.yml  ← بیلد APK در گیت‌هاب
```

## ۱) اجرای سرور روی Termux

```bash
pkg update && pkg upgrade
pkg install nodejs git
cd server
npm install
node server.js
```

سرور روی پورت 3000 بالا میاد. برای اینکه Termux وقتی صفحه خاموشه بسته نشه:

```bash
termux-wake-lock
```

داده‌ها در `server/data.json` ذخیره میشن (برای انتقال به سرور جدید فقط همین فایل رو کپی کنید).

## ۲) بیلد اپ در گیت‌هاب

1. یه ریپوی جدید در GitHub بسازید و کل این پروژه رو push کنید (شاخه `main`).
2. تب **Actions** ← workflow به اسم **Build Android APK** خودکار اجرا میشه (یا دستی Run workflow بزنید).
3. بعد از تموم شدن، پایین صفحه‌ی اجرا در بخش **Artifacts** فایل `chat-apk` رو دانلود کنید، زیپ رو باز کنید و `app-release.apk` رو نصب کنید.

## ۳) وصل کردن اپ به سرور

- **سرور روی همون گوشی (Termux):** آدرس پیش‌فرض اپ `http://127.0.0.1:3000` هست، نیازی به تغییر نیست.
- **سرور روی گوشی/کامپیوتر دیگه در همون Wi-Fi:** در صفحه ورود روی آیکن ⚙️ بزنید و آدرس رو بنویسید، مثلاً `http://192.168.1.20:3000` (آی‌پی با `ifconfig` در Termux پیدا میشه).

## ۴) انتقال به سرور واقعی (بعداً)

1. پوشه `server` رو روی سرور کپی کنید، `npm install` و `node server.js` (برای دائمی شدن: `npm i -g pm2 && pm2 start server.js`).
2. حتماً جلوی سرور HTTPS بذارید (مثلاً با Caddy یا Nginx + Let's Encrypt)، چون رمز عبورها از شبکه رد میشن.
3. در اپ آدرس سرور رو به `https://your-domain.com` تغییر بدید (اپ دوباره بیلد نمی‌خواد).

## API (برای اطلاع)

| مسیر | کار |
|---|---|
| `POST /register`, `POST /login` | ثبت‌نام / ورود (برمی‌گردونه token) |
| `GET /users?q=` | جستجوی کاربران |
| `GET /chats` | لیست گفتگوها |
| `GET /messages/:id`, `POST /messages/:id` | تاریخچه / ارسال پیام |
| `ws://.../ws?token=` | دریافت لحظه‌ای پیام |

## ۵) قابلیت‌های جدید

- پروفایل: عکس، یوزرنیم (قابل تغییر) و بیو — از آیکن پروفایل بالا-چپ ← Edit profile
- با زدن روی پروفایل/اسم طرف مقابل (در چت یا لیست) اطلاعاتش نمایش داده میشه
- روی هر پیام نگه دارید: Copy / Pin / Edit / Delete (حذف برای خودم یا برای همه)
- تیک ارسال و تیک دوتایی آبی (دیده شد)، آنلاین بودن و آخرین بازدید
- حالت تاریک: پروفایل ← Appearance (روشن / تاریک / سیستم)
- سرور رو حتماً دوباره اجرا کنید (`npm install` + `node server.js`)؛ عکس‌ها داخل `server/uploads/` ذخیره میشن.

## ۶) آپدیت بدون پاک کردن اپ

فایل `release.p12` (کلید امضای ثابت) باید کنار پوشه‌ی `app` و `server` تو ریپو باشه. همه‌ی بیلدها با همین کلید امضا میشن، پس از این به بعد APK جدید روی قبلی نصب (آپدیت) میشه.
(فقط یک بار، قبل از اولین نصب این نسخه، اپ قدیمی رو پاک کنید.) ریپو رو Private نگه دارید.

## ۷) ارسال فایل، پلیر آهنگ و مجوزها

- **ارسال فایل تا ۳۰ مگابایت:** دکمه‌ی 📎 کنار کادر پیام ← عکس/ویدیو، موسیقی یا هر فایل دیگه. متنی که تو کادر نوشته باشید میشه کپشن فایل. درصد آپلود تو چت نشون داده میشه و با زدن ✕ لغو میشه.
- **آهنگ:** سرور موقع آپلود متادیتا (عنوان، خواننده، آلبوم، مدت، کاور) رو از تگ‌های فایل می‌خونه (`music-metadata`). حباب آهنگ مثل تلگرام دکمه‌ی پخش + کاور + عنوان/خواننده + نوار پیشرفت داره؛ با زدن روی نوار بالای صفحه پلیر کامل (seek، قبلی/بعدی، سرعت ۱x تا ۲x) باز میشه.
- **مدیا سشن:** نوتیفیکیشن پخش، کنترل روی لاک‌اسکرین، دکمه‌های هدفون/بلوتوث و نمایش متادیتا (`just_audio_background`).
- **عکس‌ها** (تا ۵ مگ) داخل حباب و تمام‌صفحه نمایش داده میشن؛ بقیه‌ی فایل‌ها با زدن دانلود میشن و با برنامه‌ی مناسب باز میشن.
- **مجوزها:** بعد از اولین ورود صفحه‌ی «Permissions» (اعلان‌ها، عکس، ویدیو، موسیقی؛ تو اندروید ≤۱۲ فقط «Files & media») نشون داده میشه با وضعیت هر مجوز و دکمه‌ی Allow / Settings. بعداً هم از منوی پروفایل (آیکن بالا-چپ) ← Permissions در دسترسه.
- **سرور:** حتماً دوباره `npm install` بزنید (پکیج `music-metadata` اضافه شده). فایل‌ها داخل `server/files/` ذخیره میشن و فقط فرستنده/گیرنده می‌تونن بگیرنش (`GET /file/:messageId`).

| مسیر | کار |
|---|---|
| `POST /messages/:peer/file` | آپلود فایل (بدنه = خود فایل، هدرها: `x-file-name`, `x-caption`) |
| `GET /file/:messageId` | دانلود/استریم فایل (Range پشتیبانی میشه) |


## ۸) پروفایل جدید، پلیر، ویدیو و ارسال چندتایی

- **پروفایل مثل تلگرام:** عکس بزرگ بالا؛ چند عکس داشته باشید، نوار بخش‌بندی‌شده بالا نشون میده و با سوایپ یا زدن کنار عکس عوض میشن (وسط عکس = تمام‌صفحه). زیرش اسم، آنلاین/آخرین بازدید، دکمه‌ی Message، آهنگ پروفایل، بیو و یوزرنیم. (دکمه‌ی تماس و کانال نداره.)
- **چند عکس پروفایل:** پروفایل ← Edit profile ← بخش PHOTOS (تا ۱۰ عکس؛ انتخاب چندتایی، Make main photo، Delete).
- **آهنگ پروفایل:** دو راه: Edit profile ← Choose a song، یا داخل پلیر روی «Add to Profile» بزنید. با زدن روی آهنگ تو پروفایل کسی پخش میشه.
- **پلیر مثل تلگرام:** نوار بالا «خواننده – آهنگ»؛ با زدنش پلیر کامل با لیست آهنگ‌های چت، کاور، اسلایدر، حالت پخش (ترتیبی / تصادفی / تکرار) و دکمه‌ی Add to Profile باز میشه.
- **مدیای مشترک:** پایین‌ترِ پروفایل، تب‌های Media / Music / Files با چیزهایی که برای هم فرستادید.
- **پلیر ویدیو داخل اپ:** ویدیو تو چت پیش‌نمایش داره؛ با زدنش پلیر بزرگ باز میشه (seek، ±۱۰ ثانیه، سرعت، چرخش صفحه).
- **ارسال چند عکس/فایل همزمان:** 📎 ← انتخاب چندتایی (تا ۱۰ فایل)؛ پشت‌سرهم آپلود میشن و عکس‌ها تو گالری با سوایپ دیده میشن.
- **سرور:** دوباره اجرا کنید (`node server.js`)؛ عکس‌های قبلی خودکار به لیست عکس‌ها منتقل میشن. پکیج جدید اپ: `video_player`.

| مسیر | کار |
|---|---|
| `POST /me/photos`, `DELETE /me/photos/:id`, `POST /me/photos/:id/main` | افزودن / حذف / اصلی کردن عکس پروفایل |
| `POST /me/music` (`{messageId}` یا `{userId}`) | آهنگ از پیام یا پروفایل دیگران |
| `POST /me/music/upload`, `DELETE /me/music` | آپلود مستقیم / حذف آهنگ پروفایل |
| `GET /users/:id/music` | استریم آهنگ پروفایل |
| `GET /shared/:peer` | فایل‌های مشترک با یه کاربر |


## ۹) شیت انتخاب فایل، منوی پیام، ریپلای و ری‌اکشن

- **📎 شیت مثل تلگرام:** نوار پایینش فقط سه گزینه داره: Gallery (عکس/ویدیو به‌صورت گرید و انتخاب چندتایی)، Music (لیست آهنگ‌های گوشی)، File (Internal Storage). با کشیدن دستگیره‌ی بالا بزرگ/کوچک میشه. دکمه‌ی Send N بعد از انتخاب ظاهر میشه (تا ۱۰ فایل).
- **نگه داشتن روی پیام:** بقیه‌ی صفحه تار میشه، پیام با انیمیشن میاد وسط صفحه، بالاش ری‌اکشن‌ها و زیرش منوی شیشه‌ای (Reply / Copy / Pin / Edit / Delete). زدن بیرون از منو = بستن.
- **ریپلای:** از منو Reply رو بزنید؛ بالای کادر پیام نوار ریپلای میاد، و تو حباب نقل‌قول نشون داده میشه (با زدن روش میپره به پیام اصلی). برای فایل‌ها هم کار می‌کنه.
- **ری‌اکشن:** ❤️ 💘 💔 😂 😐 😑 🗿 😭 👾 — از منوی نگه‌داشتن؛ زیر پیام نشون داده میشه و با زدن روش برمی‌داری/عوض میشه.
- **اپ:** پکیج جدید `photo_manager`. **سرور:** دوباره اجرا کنید (روت جدید `POST /message/:id/react` و فیلد `replyTo` در ارسال پیام/فایل).

## ۱۰) صفحه‌ی اصلی با نوار شناور

- پایین صفحه یه نوار شیشه‌ای شناور با سه تب: **Profile** (آیکنش عکس پروفایله؛ اگه نبود حرف اول اسم)، **Chat** (لیست گفتگوها، تب پیش‌فرض) و **Settings** (فعلاً «Coming soon» + نسخه‌ی اپ).
- تب Profile: ویرایش پروفایل، Appearance، Permissions، Server address و Log out. **نگه داشتن** روی تب Profile منوی شیشه‌ای حساب‌ها رو باز می‌کنه (سوییچ بین اکانت‌ها + Add account).
- پکیج جدید اپ: `package_info_plus`.


## ۱۱) پشتیبانی از تم تلگرام (.attheme)

- **وارد کردن:** پروفایل ← Appearance ← **Import theme (.attheme)** و انتخاب فایل از حافظه.
- **از داخل چت:** اگه کسی فایل `.attheme` برات بفرسته، روی فایل بزن ← Apply theme.
- **برگشت:** Appearance ← Remove یا انتخاب Light / Dark / System.
- رنگ‌ها (پس‌زمینه، حباب‌ها، نوار بالا، متن‌ها، رنگ اصلی) از کلیدهای تلگرام خونده میشن و عکس پس‌زمینه‌ی داخل فایل (WPS) هم اعمال میشه. تم ذخیره میشه و بعد از بستن اپ هم می‌مونه.
- کد: `app/lib/attheme.dart` (پارسر + ذخیره + اعمال)، و مپ کلیدها تو `utils.dart` (`Pal`) و `main.dart` (`_theme`).
- پکیج جدیدی لازم نیست.


## ۱۲) ویس مسیج و ویدیو مسیج دایره‌ای

- **دکمه‌ی سمت راست کادر پیام** (وقتی متنی ننوشتید): یک بار بزنید ← بین 🎤 ویس و 📹 ویدیو مسیج عوض میشه. **نگه دارید** ← ضبط شروع میشه، **ول کنید** ← ارسال.
- **لغو:** در حین نگه داشتن انگشت رو به چپ بکشید (Slide to cancel). **قفل:** انگشت رو به بالا بکشید تا ضبط قفل بشه و بتونید ول کنید؛ بعدش سطل زباله = لغو، دکمه‌ی آبی = ارسال.
- **ویدیو مسیج:** پیش‌نمایش دایره‌ای دوربین (جلو) وسط صفحه با حلقه‌ی زمان (حداکثر ۶۰ ثانیه). ویس تا ۱۵ دقیقه.
- **پخش داخل چت:** ویس با دکمه‌ی پلی، شکل موج (با کشیدن روش seek میشه) و سرعت ۱× / ۱.۵× / ۲×. ویدیو مسیج به‌صورت دایره‌ی بدون حباب نشون داده میشه؛ با زدنش **داخل خود دایره** با صدا پخش میشه (حلقه‌ی پیشرفت دورش)، دوباره بزنید = توقف.
- هر لحظه فقط یک مدیا پخش میشه (ویس، ویدیو مسیج و موزیک همدیگه رو ساکت می‌کنن).
- **اپ:** پکیج‌های جدید `record` و `camera`، مجوزهای `RECORD_AUDIO` و `CAMERA` (بار اول که ضبط می‌کنید پرسیده میشه). `minSdk` توی workflow روی ۲۴ تنظیم میشه.
- **سرور:** فقط دوباره اجرا کنید. آپلود با هدرهای `x-media-kind` (`voice` | `round`)، `x-duration` (میلی‌ثانیه) و `x-waveform` (base64) انجام میشه؛ `kind` پیام `voice` یا `round` میشه.

### ظاهر صفحه‌ی ضبط (مثل تلگرام)
- نوار پایین: نقطه‌ی قرمز + زمان (مثلاً `0:04,8`) + **CANCEL** (بعد از قفل شدن) و دایره‌ی بزرگ ارسال سمت راست.
- دکمه‌ی **مکث/ادامه** بالای دکمه‌ی ارسال (برای ویس و ویدیو مسیج).
- ویدیو مسیج: دایره‌ی بزرگ دوربین تقریباً به عرض صفحه، با حلقه‌ی نازک و کمان سفید پیشرفت؛ پایین-چپ دکمه‌های **چراغ قوه** و **عوض کردن دوربین**.
- عوض کردن دوربین وسط ضبط ممکن نیست (پلاگین دوربین فیلم رو از بین می‌بره)؛ انتخاب برای ویدیوی بعدی ذخیره میشه.

## گیف‌ها

- موقع انتخاب ویدیو از گالری، روی ویدیوی انتخاب‌شده دکمه‌ی **Mute** میاد. اگه بزنی (می‌شه **GIF**) ویدیو به‌صورت گیف فرستاده میشه: بی‌صدا، خودکار و بی‌نهایت پخش میشه.
- روی هر گیف (یا فایل `.gif`) نگه داری، گزینه‌ی **Add to GIFs** میاد و به گیف‌های خودت اضافه میشه (تا ۲۰۰ تا، روی سرور ذخیره میشه).
- آیکن کنار کادر پیام، پنل گیف‌ها رو باز می‌کنه؛ زدن روی هر گیف همون لحظه می‌فرستتش و نگه داشتن روش حذفش می‌کنه.
- توی لیست گفتگوها، به جای ایموجی، پیش‌نمایش ریز عکس یا فریم اول ویدیو نشون داده میشه.
- سرور: `GET/POST /me/gifs`, `DELETE /me/gifs/:id`, `POST /messages/:peer/gif`

## ۱۱) اسم، فامیلی و تنظیمات حساب

- **ثبت‌نام:** فقط نام کاربری + رمز عبور (حداقل ۶ کاراکتر). بعد از ساخته شدن اکانت، بقیه‌ی مشخصات از تب **Settings** تنظیم میشه.
- **تب Settings:** اسم (First name)، فامیلی (Last name)، یوزرنیم، بیو و عکس پروفایل. با زدن روی هر ردیف یه پنجره‌ی ویرایش باز میشه؛ «Edit profile» صفحه‌ی کامل (چند عکس، آهنگ پروفایل) رو باز می‌کنه.
- **نمایش:** هرجا اسم کاربر نشون داده میشه (لیست چت‌ها، هدر چت، پروفایل، گالری) اسم + فامیلی میاد؛ اگه ست نشده باشه یوزرنیم. جستجوی چت‌ها هم روی اسم و هم یوزرنیم کار می‌کنه.
- **سرور:** فیلدهای `firstName` و `lastName` (حداکثر ۴۰ کاراکتر) به `PATCH /me` اضافه شد و تو `publicUser` برمی‌گرده؛ کاربرهای قدیمی بدون تغییر کار می‌کنن. فقط سرور رو دوباره اجرا کنید.

## قانون توسعه‌ی UI

قبل از هر تغییر ظاهری، اول ببین خود تلگرام اندروید همون بخش رو چطور پیاده کرده (سورس: https://github.com/DrKLO/Telegram — مثلاً `DialogsActivity`, `ChatActivity`, `ChatMessageCell`, `Theme.java`) و ابعاد/رنگ/رفتار رو از اون‌جا الگو بگیر؛ کد تلگرام رو کپی نکن (لایسنس GPL) و اسم/لوگوی رسمی رو استفاده نکن.

## ۱۲) چت با هدر و نوار تایپ شناور

- **هیچ چیز چسبیده نیست:** پیام‌ها تمام صفحه‌ان و از پشت هدر و نوار تایپ دیده میشن (شیشه‌ای/تار). لیست خودش بالا و پایین فاصله می‌گیره تا پیام‌ها زیر نوارها گم نشن.
- **هدر چت:** دایره‌ی عکس پروفایل (زدن = پروفایل) | مستطیل گرد با اسم و وضعیت | دایره‌ی سه‌نقطه.
  - **نگه داشتن** روی مستطیل اسم → هدر به نوار سرچ همون چت تبدیل میشه (نتایج فیلتر میشن؛ دکمه‌ی ✕ یا Back برای خروج).
  - **سه‌نقطه** → منوی **Search** و **Delete history** (Delete for me / Delete for everyone).
- **نوار تایپ:** گیره | کادر پیام (+ گیف) | ارسال/ویس، همه جدا و شناور. پین‌شده، مینی‌پلیر، ادیت و ریپلای هم شناور و گرد شدن.
- **نوار تب صفحه‌ی اصلی** از قبل شناور و شیشه‌ای بود و همین‌طور موند.
- **سرور:** روت جدید `DELETE /chat/:peer` (با `?all=1` برای هر دو طرف) و رویداد لحظه‌ای `clear`. سرور رو دوباره اجرا کنید.

## ۱۳) ایموجی‌های متحرک (Lottie / TGS)

- **اضافه کردن (فقط ادمین):** Settings ← Admin panel ← *Animated emojis* ← دکمه‌ی `+`. فایل `.tgs` یا `.json` رو انتخاب کن، پیش‌نمایشش رو ببین، ایموجی مورد نظر رو انتخاب کن (یا با کیبورد تایپ کن) و *Add* بزن. هر ایموجی فقط یک انیمیشن میتونه داشته باشه؛ برای عوض کردنش اول قبلی رو پاک کن.
- **نمایش:** هر جا اون ایموجی تو یه پیام باشه (تو هر چتی) متحرک نشون داده میشه. اگه پیام فقط ۱ تا ۳ ایموجی باشه بزرگ نشون داده میشه. تو تایپ‌باکس هم همینطوره.
- **پنل پایین تایپ‌باکس:** دکمه‌ی گیف ← پایین پنل دو تب `Emoji` و `GIF`. تب Emoji همه‌ی ایموجی‌های متحرک رو نشون میده؛ با زدن روی هرکدوم داخل تایپ‌باکس میاد و مثل متن عادی ارسال میشه.
- **سرور:** `GET /lotties`، `GET /lotties/:id/file` (همه‌ی کاربرها)، `POST /admin/lotties` و `DELETE /admin/lotties/:id` (فقط ادمین). فایل tgs سمت سرور باز میشه و همیشه به‌صورت JSON ذخیره میشه (حداکثر ۳ مگابایت).
- بعد از آپدیت: `flutter pub get` (پکیج `lottie`) و ری‌استارت سرور.

## ۱۴) بات Sticker (گیف‌ساز + پک ایموجی کاستوم)

- **پیدا کردنش:** تو صفحه‌ی اصلی، توی کادر **Search** بنویس `Sticker` ← ردیف «Sticker (BOT)» میاد. هر کسی می‌تونه بازش کنه.
- **Start:** بار اول فقط دکمه‌ی **START** هست. بعد از زدنش بات دستورها رو میگه:
  `/new_gif` ، `/new_pack` ، `/my_packs`. هر دستوری که با `/` شروع بشه و به‌هم چسبیده باشه (مثل `/new_gif`) توی پیام بات قابل لمسه و با لمس **خودکار ارسال** میشه. (زیر کادر پیام هم دکمه‌های میان‌بُر هست.)
- **`/new_gif`:** ویدیو رو با 📎 بفرست ← بات تبدیلش میکنه به گیف و تو «گیف‌های من» ذخیره میکنه (از پنل گیف کنار کادر پیام تو هر چتی میشه فرستادش). اگه `ffmpeg` روی سرور نصب باشه گیف بی‌صدا و سبک میشه (حداکثر ۲۰ ثانیه، ۴۸۰ پیکسل)؛ نصب نباشه همون ویدیو به‌عنوان گیف ذخیره میشه (موقع پخش بی‌صداست). نصب تو Termux: `pkg install ffmpeg`.
- **`/new_pack`:**
  1. اسم پک رو بفرست.
  2. یک فایل `.tgs` بفرست (با 📎، تکی‌تکی).
  3. ایموجی همون فایل رو بفرست (فقط یکی).
  4. بات تایید میکنه و میگه فایل بعدی رو بفرست. تکرار کن.
  5. `/publish` ← پک با همه‌ی چیزهایی که تا اون لحظه فرستادی و تایید شده ساخته میشه (تا ۱۲۰ ایموجی) و یه **لینک** میده: `chatapp://emoji/<id>`.
  - `/cancel` هر وقت: پک نیمه‌کاره پاک میشه.
- **لینک پک:** لینک رو تو هر چتی بفرست؛ تو حباب پیام آبی و قابل لمسه. لمسش صفحه‌ی پک رو باز میکنه با دکمه‌ی **Add N emoji** (یا Remove). پکی که میسازی خودکار تو اکانت خودت اضافه‌ست. سازنده تو صفحه‌ی پک میتونه حذفش کنه.
- **ایموجی‌های کاستوم:** دکمه‌ی گیف کنار کادر پیام ← تب **Emoji**: بالاش یه نوار تب هست (اولی ایموجی‌های ادمین، بعدش یه تب برای هر پک). تو هر پک خودِ ایموجی‌ها نشون داده میشن (نه جای ایموجی معمولی)؛ مثل ایموجی کاستوم تلگرام. زدن روی هرکدوم میذارتش تو کادر پیام و با بقیه‌ی پیام ارسال میشه. نگه داشتن روی تب پک: Copy link / Remove. ایموجی‌های کاستوم همه‌جا (چت، کادر پیام، حالت «فقط ایموجی» بزرگ) متحرک‌ان، حتی برای کسی که اون پک رو اضافه نکرده؛ تو پیش‌نمایش لیست چت و Copy یه ایموجی معمولی جاشون میاد.
- **سرور:** فقط دوباره اجرا کنید (پکیج جدیدی لازم نیست).

| مسیر | کار |
|---|---|
| `POST /sticker/gif` | بدنه = ویدیو؛ تبدیل به گیف و ذخیره تو گیف‌های من |
| `GET/POST/DELETE /packs/draft` | وضعیت / شروع (`{title}`) / لغو پک در حال ساخت |
| `POST /packs/draft/item` | `{emoji, data: base64 tgs}`؛ اضافه کردن یک ایموجی |
| `POST /packs/draft/publish` | ساخت پک و برگردوندن لینک |
| `GET /packs/:id` , `DELETE /packs/:id` | اطلاعات پک / حذف (فقط سازنده یا ادمین) |
| `GET /me/packs`, `POST/DELETE /me/packs/:id` | پک‌های اکانت من / اضافه / حذف |
| `GET /cemoji/:itemId/file` | انیمیشن یک ایموجی کاستوم (JSON) |

- **اپ:** فایل‌های جدید `sticker_bot.dart`, `custom_emoji.dart`, `ce_text.dart`؛ تغییر تو `home_page.dart`, `lottie_emoji.dart`, `chat_page.dart`, `utils.dart`, `api.dart`. پکیج جدیدی لازم نیست.
